# 한국 커뮤니티 추천 캐릭터 조합 조사 (2026-10-18 확인)

"캐릭터 만들기" 페이지의 커뮤니티 추천 조합 후보로, 한국 커뮤니티 글에서 찾은 B42 조합을 정리한다.

## 기준과 확인 방법

- 대상: Build 42 글만 쓴다. B41 글은 뺐다. 42.13(2025-12-11 unstable) 이전 글은 버전을 따로 표시했다.
- 버전 대조표(PZwiki Build 42 페이지): 42.12.x 2025-09~10, 42.13.0 2025-12-11, 42.15.x 2026-03, 42.16.x 2026-04, 42.19.0 2026-06-01, 42.20.0 stable 2026-07-29, 42.20.4 2026-08-26, 42.21.0 stable 2026-09-28. 글에 버전이 안 적혀 있으면 작성일로 추정해 "(추정)"이라고 적었다.
- 특성 id 와 비용은 `web/src/data/character.json`(42.21.0) 기준이다. "42.21 잔여"는 직업 비용 - 긍정 합 + 부정 합으로 계산했다. 0 이상이어야 실제로 만들 수 있다. 배타 관계도 같은 파일의 `exclusive` 로 검사했다.
- 읽은 방법: 네이버 블로그(PostView), 아카라이브, 디시인사이드, 인벤, 티스토리, 루리웹 페이지를 로그인 없이 직접 열어 본문과 댓글을 읽었다. 디시 "약비실" 글의 특성은 본문 그림(특성 아이콘)으로만 나와 있어 그림을 받아 확인했다.
- 루리웹: 프로젝트 좀보이드 게시판(https://bbs.ruliweb.com/game/85842)의 공략/팁 분류에 글이 없고, 유머 게시판 글에도 조합이 없어 조합 출처로는 못 썼다(팁 1건만 씀).

## 조합 목록

### 1. 약비실 경찰관 (+20 포인트 빌드)

- 출처: 디시인사이드 프로젝트 좀보이드 마이너 갤러리, "[42/공략] 초 간단 +20 포인트 약비실 극복 가이드." (작성자 화상)
- URL: https://gall.dcinside.com/mgallery/board/view/?id=pzom&no=289384
- 작성: 2026-04-07 / 버전: "42" (42.16 시기, 추정) / 조회 3,084, 추천 11
- 직업: 경찰관 (policeofficer). 대안은 퇴역 군인 (veteran). 다른 직업이면 사냥꾼(hunter)이나 과녁 사수(target_shooter) 같은 조준 특성을 하나 챙기라고 한다.
- 긍정: 속도광 (speeddemon), 잠이없는 → 잠이 적음 (needslesssleep), 소식가 (lighteater), 낮은 갈증 (lowthirst). 남는 포인트는 취향껏.
- 부정: 약함 (weak), 비실함 (unfit). 선택으로 느린 신진대사 (weightgain).
- 42.21 잔여: +8 (느린 신진대사까지 넣으면 +10). 배타 충돌 없음.
- 이유: 근력·체력 0 의 약점을 총(조준 레벨)으로 메우고, 남는 +20 포인트로 원하는 특성을 산다. 로즈우드 → 총포상 → 군장점 순서로 2일 반 만에 탄약과 거점을 확보하는 공략이 같이 있다. 중수 이상용이라고 글쓴이가 못박는다.

### 2. 멀티 정찰대·소총 사수 (경찰관)

- 출처: 디시인사이드 프로젝트 좀보이드 마이너 갤러리, "멀티 장기생존 운영방식 추천 (역할분담,거점선정,모드추천)" (작성자 좀붕이)
- URL: https://gall.dcinside.com/mgallery/board/view/?id=pzom&no=306791
- 작성: 2026-09-04 / 버전: "42빌드 안정화버전 나온지 얼마 안 됨" (42.20.x, 추정) / 조회 2,259, 추천 4
- 직업: 경찰관 (policeofficer). 좀보이드를 잘 모르는 친구, 매번 접속 못 하는 게스트에게 맡기는 역할.
- 긍정: 야구선수 → 야구 선수 (baseballplayer), 용감함 (brave). 글의 공통 규칙으로 튼튼함 → 강인함 (strong), 육상선수 → 육상 선수 (athletic) 필수, 민첩한 → 민첩함 (dextrous), 정리쟁이 (organized) 기본. 스텔스로 갈 때 우아함 (graceful), 부족한존재감 → 부족한 존재감 (inconspicuous, 선택), 체조선수 (gymnast, 선택).
- 부정: 글에 전체 목록은 없다. 포인트가 모자라면 평화주의자 (pacifist)를 넣으라고 한다.
- 42.21 잔여: 긍정 6개만으로 -38. 부정 특성으로 38점을 채워야 한다. 주의: 글에서 따로 권하는 밀실 공포증 (claustrophobic)은 용감함과 같이 고를 수 없다.
- 이유: 조준 3~4로 시작해 소총탄·소음기로 좀비 무리를 정리하고, 지도 밝히기·차량과 트레일러 조달을 맡는다. 글쓴이 서버는 경험치 4~5배라 조준시 발걸음 시작 보너스가 크다고 본다.

### 3. 멀티 건축·정비·목장 담당 (피트니스 강사)

- 출처: 2번과 같은 글.
- 직업: 피트니스 강사 (fitnessinstructor). 건축 담당은 벌목꾼 (lumberjack), 정비·대장장이 담당은 기술자 (engineer)도 대안.
- 긍정: 튼튼함 → 강인함 (strong) + 건강함 (fit)으로 근력·체력 10. 역할별로 능숙함 (handy, 건축), 정비 → 차량 지식 (mechanics, 정비), 대장장이 → 단조 지식 (blacksmith, 선택), 야구선수 → 야구 선수 (baseballplayer, 목장). 공통으로 민첩함 (dextrous), 정리쟁이 (organized).
- 부정: 댓글에서 골초 (smoker, 육상 선수를 안 찍으니 가능), 덤벙댐 (clumsy, 체력 10 이면 넘어짐 패널티 상쇄), 평화주의자 (pacifist)를 든다.
- 42.21 잔여: 강인함·건강함·야구 선수·민첩함·정리쟁이 + 골초·덤벙댐·평화주의자로 -22. 부정 특성이 더 필요하다.
- 이유: 모든 인원이 결국 전투에 나가는 서버라, 포인트를 아끼면서 체급을 올릴 수 있는 피트니스 강사를 1순위로 본다. 댓글 설명으로는 -6 직업이지만 육상 선수 대신 건강함(6)을 쓰고 골초·덤벙댐을 넣으면 사실상 +2 직업이 된다.

- 이유: 경찰은 조준·재장전·조준시 발걸음을 받아 총으로 원거리, 특성으로 근접까지 잡는 전투 직업. 퇴역 군인(-8)보다 싸고, 퇴군은 못 고르는 밀실 공포증·겁쟁이로 포인트를 벌 수 있다. 총알 운반 때문에 정리쟁이를 필수로 본다.
